# Getting help

Lancer is maintained by one person, in their spare time. There is no paid support.

1. Read the [README](README.md) and the documentation in [`packages/website/content/docs`](packages/website/content/docs).
2. If it does not help, open a [bug report](https://github.com/lancer-systems/lancer/issues/new?template=bug.yml) with the version, the AWS region and the steps. Never paste a real AWS key, token or password.
3. A security flaw is never reported in an issue: follow [SECURITY.md](SECURITY.md).

Questions and ideas go through a [feature request](https://github.com/lancer-systems/lancer/issues/new?template=feature.yml).
